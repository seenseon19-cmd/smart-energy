# SmartEnergy

تطبيق Flutter لإدارة ومراقبة استهلاك الطاقة المنزلية والتجارية، مع تحكم بالأجهزة، متابعة لحظية للقدرة، تنبيهات أمان، وإحصاءات تساعد على تقليل الهدر.

## المزايا

يقدّم التطبيق تجربة بدء كاملة تبدأ بشاشة ترحيبية وتسجيل الدخول، ثم إنشاء الحساب على ثلاث مراحل: البريد وكلمة المرور، استكمال الملف الشخصي، واختيار نوع الحساب السكني أو التجاري. بعد ذلك ينتقل المستخدم إلى مساحة عمل موحّدة تحتوي على لوحة القيادة، الأجهزة، المساحات، التحليلات، التقارير، الجدولة، سجل النشاط، الحماية، الملف الشخصي، والإعدادات.

تتضمن الواجهة نظام هوية موحّد باسم **SmartEnergy**، ودعمًا كاملًا للعربية والإنجليزية، واتجاه RTL، ووضعين فاتح وداكن مع حفظ تفضيل المستخدم قبل تشغيل التطبيق لتجنّب وميض الثيم. كما تستخدم الواجهة رسوم Lottie المحددة داخل المتطلبات في نقاط التفاعل المناسبة بدلًا من الصور العشوائية.

## البنية

```text
lib/
├── core/          # الحركات وإعدادات العرض المشتركة
├── l10n/           # الترجمة ودعم العربية والإنجليزية
├── models/         # نماذج الأجهزة والطاقة والمساحات
├── providers/      # إدارة حالة الطاقة والمظهر واللغة
├── screens/        # شاشات المصادقة، لوحة التحكم، الإحصاءات والإعدادات
├── services/       # Firebase والمصادقة والإشعارات والبصمة
├── theme/          # نظام الألوان والثيمين الفاتح والداكن
└── widgets/        # AppLogo وبطاقات الأجهزة والعدادات والتنبيهات
```

## التشغيل

يتطلب المشروع Flutter SDK حديثًا متوافقًا مع Dart 3.11 أو أحدث. بعد تثبيت Flutter، شغّل الأوامر التالية من جذر المشروع:

```bash
flutter pub get
flutter run
```

لإنشاء نسخة ويب أو أندرويد:

```bash
flutter build web
flutter build apk
```

## Firebase

يحتوي المشروع على ملفات إعداد Firebase للمنصات المدعومة. قبل تشغيل خدمات المصادقة وقاعدة البيانات والإشعارات في بيئة حقيقية، تأكد من إعداد مشروع Firebase الخاص بك وتحديث ملفات الخيارات وفق بيانات ذلك المشروع. لا تُضمّن أي أسرار خاصة بالخادم داخل التطبيق أو المستودع.

## ملاحظات الجودة

تم تضمين إغلاق تلقائي للنوافذ بعد إضافة الأجهزة والمساحات، والتحقق من تجاوز حد القدرة قبل عرض تنبيه الحمل الزائد، وإيقاف التنبيه من مزوّد الحالة، وتصفية البيانات والمؤقتات عند تسجيل الخروج مع إزالة سجل التنقل السابق.

## الترخيص

هذا المشروع غير منشور على Pub.dev ومخصص للاستخدام والتطوير الخاصين.
